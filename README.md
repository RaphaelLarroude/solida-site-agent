# Sólida Site Agent

Skill e documentação para desenvolver o site cinematográfico da Sólida, empresa de registro de marcas e propriedade intelectual.

O fluxo é inspirado no projeto [Fable Method](https://github.com/Sahir619/fable-method), especialmente na sequência **pensar → agir → provar**. Esta implementação é específica para a Sólida e não é uma cópia do projeto de referência.

## Como usar

1. Copie ou disponibilize esta pasta para o agente local.
2. Faça o agente ler `AGENTS.md` e `skills/solida-site/SKILL.md`.
3. Dê acesso à pasta do projeto e aos materiais oficiais da Sólida.
4. Execute uma tarefa por vez, começando pela auditoria.

## Regra principal

Não começar pelo efeito visual mais complexo. Primeiro produzir um inventário, uma proposta verificável e um pequeno protótipo. Cada etapa precisa registrar o que foi feito e como foi validado.

## Estrutura

- `AGENTS.md`: instruções gerais do agente.
- `skills/solida-site/SKILL.md`: skill operacional.
- `skills/solida-site/references/`: contexto, critérios e workflow.
- `LICENSES/NOTICE.md`: atribuição e regras de referência.
