# Instruções do agente — Sólida

Antes de editar:

1. Leia `skills/solida-site/SKILL.md`.
2. Leia os arquivos em `skills/solida-site/references/`.
3. Inspecione o projeto e os materiais disponíveis.
4. Identifique campos, assets ou decisões ausentes.
5. Não invente conteúdo comercial, jurídico, depoimentos ou garantias.

## Loop obrigatório

Para cada tarefa, use o ciclo:

- **Pensar:** descreva objetivo, arquivos envolvidos, riscos e critério de sucesso.
- **Agir:** faça a menor alteração coerente com a tarefa.
- **Provar:** execute build/testes, examine erros e capture evidências quando possível.

## Segurança

- Nunca exponha secrets, tokens, credenciais ou dados pessoais.
- Não publique em Vercel, GitHub Pages ou domínio sem autorização explícita.
- Não apague referências ou assets originais.
- Registre dependências novas e licenças.

## Qualidade

- Preserve o conteúdo essencial fora do canvas WebGL.
- Inclua teclado, toque, `prefers-reduced-motion` e fallback sem WebGL.
- Meça desempenho em vez de afirmar que está otimizado.
- Não declare concluído sem evidência.
